# Web 家庭账本设计基线

本基线用于桌面 Web、移动 Web 和 PWA 的设计和验收。跨端体验以 Android `v0.1.11` 为当前参照。本文记录目标设计，功能交付状态见[实施状态](implementation-status.md)。

## 产品定位

家庭账本是面向全家或单个成员的只读报表。默认打开「本月 · 全家」。核心路径是看收支、比较趋势和分类、查组成数字的交易。个人账本负责记账、编辑和管理账户。家庭报表遵循现有的家庭读取权限。

桌面顶栏的「家庭账本」与「统计」同级，复用同款图标按钮和选中态。移动 Web/PWA 从首页进入，复用移动页面的标题栏与返回交互。Android 保持导航抽屉入口。各端支持同一项家庭分析任务，入口服从各端导航结构。

## 报表与交互

| 区域 | 设计要求 |
| --- | --- |
| 期间和成员 | 顶部显示月／年、当前期间及全家／成员。桌面和移动端复用各自的月份选择组件。年份网格可直接选取当前年份附近的选项，跳转输入支持 1970–9998。成员范围作用于整份报表。 |
| 收支总览 | 展示支出、收入、结余及日均／月均支出。月报以该月自然日为分母。年报分母为有至少一天收入或支出净额非零的月份数，年报汇总表的平均行也用此分母。金额按分计算，平均值舍入到分，正好半分时取偶数分。分母为零时显示零。 |
| 趋势 | 月报按日，年报按月。月报可看支出、收入或全部，年报另可单看结余。系列筛选与顶部刻度预留约 16px 可见间距。沿用 Web 个人统计的柱状图、折线图和放大交互。 |
| 分类 | 默认支出，可切到收入。环图在上，一级分类列表在下。点一级分类行或扇区打开二级分类环图和列表，点二级分类查看流水。两级均保留期间、成员、收支类型和上期差额。 |
| 日期汇总 | 月报展示收入或支出净额非零的日期，年报展示包含此类日期的月份，均按倒序排列。年报含平均行。两端均可从月报日期下钻。Web 年报的月份行可打开同成员范围的月报，该入口是 Android 待对齐项。 |
| 成员与账户 | 全家范围在报表下半区展示成员对比，Web 点成员行可切换整份报表。「当前账户余额」按成员分组，随成员范围切换，金额使用账户原币种。 |

桌面 Web 和移动 Web/PWA 按总览、趋势、分类、日期汇总、成员与账户的顺序纵向阅读。趋势卡片占满报表宽度，桌面图表区域高 240px。桌面分类内容最多 760px，环图居中，排行金额靠右。展开分类时，后续卡片随页面下移。各端优先复用同端个人页面的导航、筛选、图表、金额、流水行和状态组件，共享可复用的数据转换与格式化。主题、图标、间距和焦点样式沿用 Web 现有设计。

报表下钻继承期间、成员和触发维度。明细沿用流水行样式，打开交易可看归属成员、账户、金额、备注和已有附件。移动端在应用内浏览附件，可切换多张图片。关闭图片预览后回到原交易和附件位置，关闭明细后回到原分类行。本人交易可从只读详情点「在个人账本中打开」，返回后刷新原报表并保留筛选。Android 当前从分类行和月报日期打开只读流水，附件预览和直达个人账本属于 Web 增强。

## 统计口径与次级入口

- 报表、报表下钻和汇总 CSV 共用相同口径。按上海时区的自然月或自然年统计人民币收入和支出，退款按负值计入，家庭内部往来排除。存在外币时在总览旁显示未计入笔数。
- 环图用正净额为分母。负净额保留原符号，计入净支出或净收入，并可以从列表下钻。没有正净额时显示说明和分类列表。每级环图最多单列六个正净额分类，其余合并为「其余分类」。列表首屏六条，可展开全部。环图可拖动旋转，列表保留按钮操作。
- 「全部家庭流水」是次级只读入口，继承报表期间和成员，进入后可独立切换。流水按时间倒序分页，包含外币和内部往来，交易详情与报表下钻共用。
- 「导出汇总 CSV」置于报表次级操作，继承当前期间和成员，支持月报和年报的全家或单成员汇总。

## 跨端复审与验收

定位、默认值、报表顺序、分析维度、只读边界和共同下钻与 Android 已发布体验一致。月份下钻、完整流水、附件、CSV、本人跳转和成员行快捷筛选是 Web 增强。有负分类净额时的图表是跨端对齐项。

实装验收以同一份测试账本核对 Android 与 Web。在本月全家报表中切换成员，查看分类与上期差额，打开流水和详情，再返回原位置。样例需覆盖负净额退款、外币、内部往来及年报平均分母，核对范围、数字、图表解释与明细。桌面和移动 Web/PWA 均完成核心路径，另验收浅色、深色、窄屏、键盘操作、加载、空结果和失败重试。效果图使用演示数据，实装后进行双端实机验收。

### 本次实现复验

- 桌面和移动 Web 均用生产构建、真实登录和隔离 SQLite 账本完成验证。检查了成员切换、分类与日期下钻、年报返回焦点、完整流水的独立期间和成员筛选、附件、打开本人交易并刷新、汇总 CSV，以及网络失败后的重试。移动视口覆盖 390px 和 375px，检查了 PWA manifest 和 service worker。
- Android 36 模拟器使用 `0.1.11` 调试包连接同一账本。全家与单成员的月报总览、年报月均、按日下钻和单笔退款详情的金额一致。Web 沿用 Android 家庭页的环图阅读顺序，一级到二级的查看方式参考 Android 个人报表。现有 Android 流水列表按支出幅度展示，单笔详情显示负号。
- 代码与界面复审通过。两轮复审确认了退款符号、上海历史时区、返回焦点和移动交互。浏览器界面复验覆盖浅色、深色、窄屏，以及筛选和明细的键盘操作。
