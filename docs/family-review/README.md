## 结论摘要

**当前采用已确认的家庭自用简化方案。** 完整决策和验收口径以 [简化版范围与维护方案](simplified-scope.md) 为准；它取代原需求中的通用家庭、细粒度授权、三库兼容、旧库迁移等条款。

规划时工程估算为 **17 / 28 / 45 人天（乐观 / 正常 / 悲观）**，以熟悉Go/Vue工程师计算，包含必要测试、双登录验收和备份恢复；不是AI运行时长或日历工期承诺。原完整需求57/95/153人天及原首阶段35–50人天估算不再适用。

初始评审的仓库提交为 `82920c62fd774b95eaed7fe78938675b56b73cf2`，标称 **2.2.0 开发版**；当时核实的最新稳定为 **v2.1.1 / `3dcc316e1fb6a190d6a0dd13fbe4052d17b9315c`**，开发主线比其多96个提交。早期提出另开稳定版分支，后续实际实施选择及理由见实施状态。初始核验确认认证/IP公告的修复下限为≥2.1.0；当时未确认CVE-2025-65519首个修复版，不能宣称达到某版本就消除全部漏洞。[上游核验及一手来源](upstream-verification.md)

**初始有限静态审查没有找到足以认定后门或恶意代码的证据，但没有完成需求所要求的全源码逐行通读、逐包实现审计、镜像比对与动态渗透，因此不是完整安全审计通过。** 当时定位默认密钥回退、CSV公式防护缺失、query/TOTP/AI日志隐私风险、上传限制与脚本联网等加固项；npm audit返回27个受影响包节点（critical 1），govulncheck缺失、go mod verify受缓存权限影响。后续修复和依赖检查结果见实施状态，不沿用这些早期结果判断当前版本。

用户已确认：单实例单家庭、最多10人、新SQLite库；全家共享分类/标签，互相可看交易/余额/附件但只能改本人账；管理员手动开通/停用；当前启用成员全部历史纳入人民币汇总；内部往来人工分类排除。移动优先、公网HTTPS、账密与Pocket ID进入同一账号、沿用30天使用时续期。引用字典只隐藏、家庭汇总CSV、每日备份且实测恢复；不做离线同步、角色授权平台、历史汇率或完整审计界面。AI/MCP/地图默认关闭。

主范围已确认；评审后补充全应用只用内置图标、固定上海统计时区、负净支出图表规则和恢复后的会话清理。已确认首版关闭自动定时记账、保留普通手动模板，备份等其他定时任务照常运行；实现细节和实际环境核验由开发处理。专业全量安全审计、三数据库和旧库迁移不再作为首阶段交付，但此前发现的实际公网安全问题仍需处置。

初始评审阶段只新增评审文档，当时未修改业务代码、依赖、Git远程、homelab配置或运行中服务。后续已实施业务修改并进行独立验收，准确结果和剩余项以实施状态为准。**本项目仍不承诺全面安全审计通过。**
