# webapp-v0.1.11

`ezbookkeeping-family` Webapp 0.1.11 包含 Go 后端、桌面 Web、移动 Web 和 PWA。

## 更新内容

- 家庭账本按收支总览、趋势、分类和日期汇总纵向展示。月份、年份、成员和图表系列沿用 Webapp 的现有控件。
- 分类报表先展示环图和一级分类，再下钻到二级分类及流水。退款保留负值并计入净额。
- 新增独立筛选的全部家庭流水和按当前报表范围导出的汇总 CSV。交易详情提供附件预览，本人的交易可跳转至个人账本。
- 家庭报表按上海时区统计人民币收支，保留外币未计入提示和家庭内部往来的排除规则。

## 验收

- 桌面和移动 Web 已完成人工验收。浏览器回归覆盖期间与成员筛选、分类下钻、返回和附件预览。
- 发布工作流构建并验证镜像，生成包含镜像 digest 的发布清单及校验和。
