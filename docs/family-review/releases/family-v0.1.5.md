# family-v0.1.5

家庭记账共享分类支持在线管理，按目录版本保护并发写入；单笔交易可携带分类版本，避免编辑期间分类变化被静默使用。分类改名和调整二级归属保留分类 ID，隐藏和删除提供影响提示；历史引用分类不能删除。旧客户端可继续读取和记账，但分类管理需要升级。

本版增加 SQLite 分类版本表，升级前必须按 homelab 运行手册准备一致性备份并验证匹配恢复资料；跨 schema 回退应恢复同一快照的数据、配置和对应镜像。批量交易、导入与批量更新不受单笔交易版本校验保护。

Android 客户端作为独立工件发布，不包含在此镜像中。真实手机和完整页面视觉验收需在部署后另行进行。
