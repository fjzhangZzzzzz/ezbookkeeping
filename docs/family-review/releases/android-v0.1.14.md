# android-v0.1.14

- 包名 `top.fjzhang233.books`
- versionCode `16`
- 上一正式版本 `android-v0.1.13`

## 更新内容

- 设置中的家庭共享分类支持拖拽排序，记账分类与默认项遵循排序结果。
- 统一账单详情、分类统计、账户管理和登录设备设置的操作及显示。
- 秒开模式有可用缓存时直接进入记账页。改进深色键盘反馈，支持可关闭的按键触感、长按清空，以及切换收支类型时保留草稿分类。
- 保存确认后返回来源页面，流水按月、日管理刷新状态。最近七日汇总、账户余额分别更新和重试。保存优先于后台读取，被中断的记账资料刷新会恢复。

## 验证范围

- Android 单测、Lint、Debug 构建和测试 APK 构建。
- Android 15 模拟器回归覆盖秒开首键、分类切换、跨日编辑、慢网保存与重试、余额更新、迟到响应和左右边缘返回。
- 正式 APK、OTA 元数据和摘要由 Android Release workflow 生成及校验。
