# android-v0.1.10

- 产品：`ezbookkeeping-family`
- 发布单元：Android 原生客户端
- 包名：`top.fjzhang233.books`
- versionCode：`12`
- 基于：`android-v0.1.9`

## 更新内容

- 保存账单成功后静默返回流水。「再记」成功后清空金额并继续编辑。只有未能确认保存结果时才提示核对原记录，后台刷新失败可在账本页内重试。
- 设置中显示家庭默认货币人民币。人民币流水省略币种，历史外币在金额同行保留币种。
- 搜索结果使用更紧凑的流水行。日收入为零时只展示日支出，同日流水使用更浅的分隔线。
- 左侧导航抽屉开合时带动流水首页滑动，点选导航项后先收起抽屉再切换页面。

## 验证范围

- Android 单测、Lint、调试构建和模拟器回归通过，六项交互改动已在模拟器上完成人工验收。
- 执行了延迟保存响应与结果未知的回归，确认只有结果未知时才弹出核对界面，且重试沿用原记录。
- GitHub Actions 负责正式签名、APK 校验和发布 `ezbookkeeping-android-0.1.10.apk`、`update.json`、`SHA256SUMS`。
