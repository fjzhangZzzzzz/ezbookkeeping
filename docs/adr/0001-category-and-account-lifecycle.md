# 分类与资金账户生命周期

**状态：accepted（2026-11-17）**

家庭账本采用实例级共享分类，交易继续选择二级分类，一级分类只负责分组与展开；分类重命名保留稳定 ID、历史引用和跨设备同步语义，系统内部往来分类保留稳定标记，不能当普通分类删除或改义。为保证移动端网格可读性，家庭共享分类的产品维护规范为名称不超过四个汉字；Android 编辑入口强制该限制，其他入口不得把这一视觉规范误写成新的数据库迁移约束。分类选择与管理界面保持钱迹式父类行、原位二级面板、统一图标槽位及浅色/深色主题，但不复制钱迹私有资源。

资金账户保留为交易归属和余额边界；新记账默认使用用户设置的默认账户，用户仍可在记账页切换。账户列表和排序跨客户端同步。删除入口先读取引用、余额和默认状态：空余额且无交易、转账或模板引用时永久删除；存在任一引用或余额时自动归档并保留历史；删除默认账户前先切换到可用账户。归档账户可在管理入口恢复，历史交易不改写。

该决策把产品语义集中在应用仓库；部署、备份、恢复和生产验收仍由 `homelab-infra` 唯一负责。
