# 家庭账本 Android

原生 Kotlin / Jetpack Compose 客户端，复用 Go HTTP API；没有 WebView、内嵌浏览器页面或 APK 内的 OIDC 客户端密钥。正式包固定连接 `https://books.fjzhang233.top`。本地密码登录兼容现有服务；原生 Pocket ID 登录及关联要求服务端提供 native start/exchange/cancel 接口，旧服务返回明确升级提示。

## 构建与测试

工具链固定 Java 17、Gradle Wrapper 8.13、AGP 8.13.2、Kotlin/Compose Compiler 2.2.21、SDK 36，最低 Android 8 / API 26。当前 Android `0.1.17` 使用 `versionCode=19`。已公开的 `0.1.0` / code 2 及其签名保持不可变；后续版本号和代码号单调递增。Wrapper JAR 和分发 ZIP 均采用官方 SHA256。使用系统 Gradle 不代替已核验 wrapper。

```sh
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug
./gradlew -PdebugApiBaseUrl=http://10.0.2.2:18090 assembleDebug assembleDebugAndroidTest
```

如模拟器宿主代理导致 `10.0.2.2` 不可用，可针对明确选定的隔离模拟器配置 `adb -s <模拟器ID> reverse tcp:18090 tcp:18090`，并以 `-PdebugApiBaseUrl=http://127.0.0.1:18090` 重建；合成 OIDC 夹具同时转发 18091。后端 RootUrl 与合成 issuer 也须使用对应回环地址，不修改正式网络策略。集成测试从目标应用私有 `files/qa-config.json` 读取合成输入，禁止把账号密码放入 runner 参数或提交到 Git。

Debug 网络配置仅额外允许模拟器 `10.0.2.2` 和本机 `127.0.0.1` 的 HTTP。Release 固定 HTTPS 且不允许明文。测试仅用隔离后端及合成账号，不使用生产账户或令牌；未配置真实集成测试输入时跳过集成用例，不把跳过当通过。

Release 签名只读取环境 `ANDROID_KEYSTORE_PATH`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`；缺项失败，绝不退回 Debug 签名。私钥、密码和渲染的签名文件禁止进入源码、日志或 Release。正式签名/资产发布流程见 [Android 发布手册](../docs/family-review/android-release.md)。

## 界面与会话

界面以用户熟悉的钱迹 Android 交互为参照，使用真实 Compose 控件：抽屉导航、个人月收支及日分组流水、五列分类网格、紧凑账户/日期/备注/标签/附图、固定数字键盘和「再记/保存」。默认深色、系统中文字体、48dp 最小触控、明确错误及空态；家庭是抽屉中的独立能力，不添加多账本、预算或报销占位入口。个人月/日统计取完整统计接口，按上海月份查询并分页显示流水，CNY 汇总明确排除外币；家庭也采用 CNY / Asia/Shanghai，跨成员只读。服务器继续承担所有权限校验。金额用整数分和 BigDecimal，不经 Double 换算；交易新建使用可恢复的请求 ID，未知结果重试保留同一键。

界面参照以[钱迹官方 Android 4.5.5 / code 1242 APK](https://app.qianjiapp.com/qianji_455_1242_gw.apk)在专用模拟器中的真实原生操作为准：1080×2400、density 420、fontScale 1.0、Asia/Shanghai、简体中文、原生夜间主题和虚构本地账目。已实测居中记账 FAB、五列网格、独立数字按键、原位备注唤 IME、日期滚轮、详情 sheet 以及再记清金额备注并保留分类时间。背景/区域/选中和收支色由实际截图测量；不复制钱迹私有图标、背景照片或受限业务。分类和账户图标复用本项目已有 Line Awesome 1.3.0 字体与 builtin ID，原许可证随 APK 保留。

参考应用的资产/转账、分类管理、标签管理受未登录条件限制，图片入口在可用本地模式未暴露；这些页面不能声称已完成逐屏对照，也不为研究创建在线身份或绕过门槛。本客户端自己的附件、家庭和权限仍按现有 API 实现。再记保留分类/账户/时间、清空金额/备注/标签/附件；仅分类时间及金额备注的对应参考行为已直接验证，其余是本客户端的安全处理。确认服务端写入成功后才重置并生成下一笔幂等键。个人七日柱图使用完整 daily API 的真实 CNY 数据，日历按上海日期查询并分页；图表比例才使用浮点，所有金融合计保留整数精度。

密码仅在内存短暂使用。普通会话通过 AndroidKeyStore AES-GCM 加密持久化，备份关闭；短时 native PKCE 状态也加密保管，回调 URL 只允许一次性 code/state。系统浏览器通过服务端固定 native/start 入口前往 Pocket ID；首次绑定仍确认原本地密码，不新增用户。会话续签先保存新令牌，再撤销旧 tokenId；普通会话被撤销后下次请求清理登录态，临时密码/验证码错误不删除既有普通会话。

## 账户、分类和标签保存的未知结果

这些接口没有持久幂等结果协议。客户端在发送前加密保存固定的原请求，忙碌时禁止编辑和关闭；响应不明时不再发送原请求，也不新建另一份保存。只读核实状态恢复原名称、金额、币种及所属设置，用户应先检查实际列表或网页，再明确结束本地意图。结束意图不撤销服务器可能已保存的更改，也不表示服务器保存成功。写入成功后的刷新失败单独提示“已保存，数据刷新失败”。

待核实意图按部署源和真实 UID 绑定、使用现有 AndroidKeyStore 加密并排除系统备份。UID 来源依赖当前后端受保护 `/api/v1/tokens/list.json` 的唯一 `isCurrent=true`、普通类型条目及 `tokenId` 的 `uid:createdUnixTime:userTokenId` 格式；客户端严格验证数字范围，有本人账户时还与 fresh own/family 全局账户 ID 关联交叉核对。这里使用的是服务端设备记录 ID，Bearer 凭据不进入该解析。该依赖对应现行后端 `TokenListHandler`、`GenerateTokenId` 和 `ParseFromTokenId`；后端协议更新须重新验证，未知格式或身份不一致会阻断资料写入，不降级为邮箱/昵称匹配。

进程重建、登出或身份核对网络失败不会丢弃原意图；换用户时隐藏原内容并拒绝结束。持久化完成后若在真正发出 HTTP 前崩溃，也归为“结果待核实”，不能说已经提交。未启用 OAuth 的后端只在外部关联列表确实返回 HTTP 404 且没有应用授权错误时视为功能关闭；401、网络及服务端错误继续报告。

## 更新

客户端只向固定部署环境 `https://books.fjzhang233.top/android/update.json` 匿名检查更新，不查询 GitHub，也没有 GitHub 回退。首次启动和回前台有界检查，手动检查始终重新请求，不把失败或旧缓存当成当前部署版本。manifest 请求显式 `Cache-Control: no-cache`，响应最大 64 KiB；ETag 存在时仅自动检查使用条件重验，不依赖服务器提供 ETag。schemaVersion 1 / stable 的原字段由 CI 生成不可变原件，再由 Ansible 选择部署；客户端不接受元数据中的任意下载 URL，而从严格版本号和文件名唯一导出 `/android/releases/<versionName>/ezbookkeeping-android-<versionName>.apk`。`ezbookkeeping-android-<versionName>.apk` 是稳定客户端协议；CI 不得使用 `ezbookkeeping-family-android-*` 替代。manifest 与 APK 拒绝所有 HTTP 跳转、附加 query/fragment、凭据 URL 和跨源请求，绝不携带应用 Bearer、Cookie 或 OIDC 凭据。

APK 独立于 Go 后端镜像，通过固定父目录只读挂载，由后端 `/android/` 静态路由提供。切换 manifest 不意味着修改不可变 APK；同版本不同摘要必须由部署端拒绝。GitHub Release 仅是 CI 发行及灾备来源，不是客户端的运行时检查或下载入口。正式证书仍为既有专用签名身份。

发现新版本仅提示，确认后才下载。下载限 100 MiB、使用唯一临时文件并支持取消；本地复验 SHA、实际包名、versionName/versionCode、最低系统版本及固定/已安装签名后才进入系统安装确认。SHA 只是完整性信息，不能代替签名身份。已下载状态仅持久化非秘密版本元数据和缓存文件名，返回安装权限设置后重新校验。自托管使用独立缓存命名空间并清除旧 GitHub pending；无静默安装、降级、通知权限或常驻更新服务。

旧 `0.1.0` / code 2 的已发布更新器固定查询 GitHub，无法通过服务器配置自动换源。迁移时须从 books 的正式 HTTPS 路径手动下载安装一次 `0.1.1` / code 3，同签名保留数据；此后的检查和下载全部使用自托管源。自托管 OTA 正向验收使用 ignored 隔离源码副本构建明确标注 internal 的同签名低代码号前驱，不覆盖公开 code 2，不在主线提供任意版本覆盖开关；只验证新更新链路，不用重复已通过的金融/UI 回归。

## Android 界面与交互验收

以专用模拟器内实际安装的钱迹 Android `4.5.5-1242`、中文深色为参照，固定 `1080×2400`、`density=420`、`fontScale=1.0`、`Asia/Shanghai`。只使用虚构数据；参考应用不登录真实账号、不导入个人账目、不购买或绕过登录限制。以下检查用于熟悉的操作结构，不要求复制钱迹私有图标、背景或超出本产品范围的功能。

| 范围 | 通过标准 |
|---|---|
| 首页与导航 | 月支出主值、收入/结余、真实最近七日支出、日期分组和日汇总层级清楚；汉堡抽屉、居中记账入口、日历/月报入口与实际操作对应。统计来自完整范围 API，不用首屏分页数据伪造总计；日期/币种口径一致。 |
| 记账类型与分类 | 支出/收入切换、五列网格、选中态、分类层级和滚动可用；金额键盘与备注/标签/账户/时间/附件入口位置稳定，收入与支出金额含义清楚。保留本产品转账功能，不能因参考未登录时无资产入口而删除。 |
| 日期与标签 | 日期三轮或实际约定模式、今/昨/前/时间、取消/确定有正确反馈，取消不误提交；标签紧凑弹窗有同排标题/管理/保存，选择后保存至草稿、取消不提交，进入管理后选择不丢失。参考空标签页可作结构证据，不能据此声称其实际多标签管理已实测。 |

| 再记、保存与返回 | 再记成功留在编辑页，清金额/备注并保留已选分类、日期时间及本产品账户；普通保存成功关闭并刷新流水、余额、汇总。切换收支保留已输入金额且选择有效分类。非空 X 按参考直接离开且不保存；系统返回按明确草稿规则处理，不误存或退出到其他应用；抽屉 Back 先关闭抽屉。成功/错误反馈不持久挤占布局或遮挡主要操作。 |

| 持久化交叉核对 | 保存动作须与 API/只读数据核对：恰一条目标交易、正确类型和最小单位金额、账户余额相对基线变化、正确标签/附件关联；原附件 SHA256 与指定输入一致。失败重试验证幂等，无重复扣款；保留基线和脱敏结果，不把凭据、token或带认证参数的 URL 放入证据。 |
| 本产品独立能力 | 家庭共享视图、仅修改本人数据、禁用/会话撤销、Pocket ID与密码同 UID、设备会话及 自托管更新确认下载/系统安装，分别按本产品契约验收，不从钱迹截图或界面相似推导通过。真实手机/Passkey和覆盖升级结果单列，不能由模拟器代替。 |

每组证据记录实际 APK SHA256/版本、设备基线、捕获前后前台包名双守卫、同一状态原 PNG/XML及 SHA256，并关联真实点击轨迹和必要 API 结果。先核包名，排除误退 Activity 后拍到参考应用的图；不以源码已改或构建成功代替验收。对照保留原像素，不裁剪、遮罩或移位掩盖整体布局，给出可直接打开的并排图与简明评审，JSON仅用于追溯。
